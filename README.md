## About This Repository

This repository demonstrates how I designed and implemented selected portfolio pages using custom HTML, CSS, and JavaScript inside WordPress and Elementor HTML widgets.

Web development is not my primary professional domain. This work demonstrates my ability to learn independently, build responsive interfaces, organize technical content, and operate a self-hosted production website.
